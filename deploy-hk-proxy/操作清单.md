# Supabase 香港中转 — 操作清单

> 目标：把「手机流量 → 新加坡 Supabase」换成「手机流量 → 香港中转（30ms）→ 机房专线 → Supabase」
> 效果：延迟从实测 1~3.3 秒降到约 0.03~0.08 秒，晚高峰稳定；代码零改动，只换一个环境变量。

---

## 第一步：买服务器（约 10 分钟）

| 项目 | 怎么选 |
|---|---|
| 产品 | 腾讯云「轻量应用服务器」→ [cloud.tencent.com/product/lighthouse](https://cloud.tencent.com/product/lighthouse) |
| 地域 | **中国香港**（必须，免备案 + 离深圳最近） |
| 规格 | 最便宜的 2C2G 即可（约 ¥32/月，可选 ¥288/年 更划算） |
| 镜像 | **Ubuntu 22.04 / 24.04** |
| 登录方式 | 设置密码（记住密码，后面要用） |

买完后在控制台**防火墙**里放行端口：`22`（默认已开）、`80`、`443`。

## 第二步：买域名并解析（约 15 分钟，可与服务器的 DNS 生效并行）

1. 腾讯云买一个域名（`.top` / `.xyz` 首年几块钱，`.com` 几十元）
2. 域名需要**实名认证**（上传身份证，通常几分钟到几小时通过）
3. 控制台 → 域名解析 → 添加记录：

| 主机记录 | 记录类型 | 记录值 |
|---|---|---|
| `sb` | A | 你服务器的公网 IP |

> 例如域名是 `example.top`，那代理地址就是 `sb.example.top`。
> 香港服务器**不需要 ICP 备案**，解析生效即可用。

## 第三步：跑一键脚本（约 5 分钟）

在服务器控制台点「登录」（网页版终端），或用你自己的 SSH 工具连接，然后：

```bash
# 把脚本内容粘贴进去（本地文件：deploy-hk-proxy/setup_server.sh）
# 或者用 scp 传上去后执行：
sudo bash setup_server.sh sb.你的域名.com
```

脚本自动完成：装 nginx → 写反代配置（含 Realtime WebSocket）→ 签发 HTTPS 证书 → 验证。
看到 `HTTP 401 即为正常` 就说明代理已通。

> 需要的话把服务器 IP 和密码给 AI，我可以远程帮你跑并排错。

## 第四步：切换前端（AI 来做）

| # | 动作 | 谁做 |
|---|---|---|
| 1 | 改 `deploy-main.ps1` / `deploy-git.bat` 里的 `VITE_SUPABASE_URL` → `https://sb.你的域名.com` | AI |
| 2 | Cloudflare Pages 后台 → Settings → Environment variables → 同步改 URL（Git 自动部署那条路径用） | 你（1 分钟） |
| 3 | 重新构建 + wrangler 部署上线 | AI |
| 4 | 线上验证延迟对比（curl 实测数据） | AI |

anon key 不变，数据库不用动，数据不迁移。
